# Portfolio

A personal portfolio website built with pure HTML, CSS, and JavaScript — no build tools or frameworks required.

## Features

- **Responsive design** — looks great on desktop, tablet, and mobile
- **Smooth scroll & fade-in animations** on all major sections
- **Sticky navbar** with mobile hamburger menu
- **Hero section** with name, title, and social links
- **About section** showcasing background and personality
- **Skills grid** with icon-based skill cards
- **Projects section** with tech tags and links
- **Contact form** with client-side validation
- **Dark theme** throughout

## Usage

Simply open `index.html` in any modern browser — no installation needed.

```
open index.html
```

## Structure

```
Portfolio/
├── index.html   # Main page
├── style.css    # Styles
└── script.js    # Interactivity
```

## Customisation

Update `index.html` to replace placeholder content:
- Name and title in the Hero section
- About Me text
- Skill cards
- Project cards (name, description, tags, links)
- Contact email and social profile URLs
